# SLM browser app

https://12334bruno.github.io/slm-demo/

The application runs on your device with Python/WebAssembly and browser OCR. Projects and uploads are saved in your browser. The grant catalogue and retained official forms are a static snapshot. Selected company text is sent to Groq when cloud AI is enabled. Settings lets you replace the intentionally public shared prototype API key with your own. The snapshot contains public grant data only; local companies, uploaded company documents and private settings are excluded.
