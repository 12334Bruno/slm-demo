# SLM visual preview

https://12334bruno.github.io/slm-demo/

This standalone preview demonstrates the current interface with fictional sample profiles, grants, eligibility checks and applications. It runs entirely in the browser and stays available when the development computer is off.

Profile edits, saved grants, application answers, budgets and checklists stay in that visitor's browser. AI writing, live discovery, website research, file uploads and email signup are not connected. Download buttons provide clearly identified sample documents; edited preview data is not included in those sample files.

The source fixture data was generated from an isolated test server using fictional documents. This deployment contains only static frontend assets and generated sample downloads. It excludes API credentials, local workspaces, private uploads and background documents.
